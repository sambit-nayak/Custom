# Pooja Birthday Surprise ❤️

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Copy `index.html` into the root of your GitHub repository.
2. Commit and push to the `main` branch.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Your URL will usually be:
   https://sambit-nayak.github.io/Custom/

## Customize
- Replace the memory cards in `index.html` with `<img>` tags pointing to your photos.
- Add your music file and wire it to the Music button.
- Edit the wedding timeline and any text you want.


Updated premium edition: cinematic glassmorphism, directional transitions, swipe navigation, keyboard navigation, and polished gift reveal.
